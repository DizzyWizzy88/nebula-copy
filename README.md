# Nebula Copy 🌌

> Out-of-this-world copy, in seconds.

Nebula Copy is a high-margin Micro-SaaS application designed for generating social media copy with dynamic tone controls, platform formatting, and a integrated Stripe Pro subscription model ($12.99/mo).

## Tech Stack
- **Frontend:** HTML5, Tailwind CSS, Native ES6 JavaScript (compatible with Web & Android WebView).
- **Backend:** Node.js, Express, Stripe API.
- **Monetization:** Stripe Checkout (Subscriptions) & Webhooks.
